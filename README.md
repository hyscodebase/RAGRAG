# RAG Study Workspace

RAG 학습 실습 자료를 주차별로 정리하는 저장소입니다.

## Structure

- `weeks/`: 주차별 학습 폴더
- `docs/`: 로드맵, 진행 기록
- `resources/`: 여러 주차에서 공용으로 쓰는 자료
- `requirements.txt`: 실습 환경 패키지

## Current Mapping

- `week01_search-basics`: 코사인 유사도와 검색 기초
- `week02_chunking`: 텍스트 청킹 실습

## Usage Rule

각 주차는 아래 구조를 기본으로 사용합니다.

```text
weekXX_topic/
  README.md
  notes.md
  practice/
  data/
```

실습 노트북은 `practice/`, 원문 PDF나 샘플 데이터는 `data/`, 공부 정리는 `notes.md`에 누적하면 됩니다.
