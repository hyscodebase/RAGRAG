# Week 02 Vector Database Basics

## Goal

RAG에서 문서를 임베딩한 뒤 어디에 저장하고 어떻게 빠르게 찾는지 이해합니다.

## Focus

- Vector Index와 Vector Database의 차이
- Indexing과 Querying의 전체 흐름
- ANN 검색과 정확도-속도 tradeoff
- Hash, Tree, IVF, HNSW 인덱스 구조 개념
- Scalar Quantization, Product Quantization 기초
- Keyword, Sparse, Dense, Hybrid Search의 차이
- Vector DB 제품군을 보는 기준
