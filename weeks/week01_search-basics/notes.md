# Week 01 Notes

## Summary

- 기업용 RAG는 단순 검색 기능이 아니라 보안, 네트워크, 권한 통제가 함께 설계되어야 함
- 파인튜닝은 모델의 행동 패턴을 바꾸는 데 강하고, RAG는 최신 사내 지식을 연결하는 데 강함
- RAG 파이프라인은 적재 단계와 질의 단계로 나눠서 보는 것이 이해에 가장 좋음
- 청킹은 retrieval 품질을 좌우하는 핵심 설계 요소이며, 크기와 경계 처리의 균형이 중요함

## Key Concepts

- VNET: 모델 호출 경로를 사설 네트워크 안쪽으로 제한해 외부 노출을 줄이는 방식
- 온프레미스: 민감 문서와 시스템을 사내 인프라 안에서 직접 운영하는 방식
- 콘텐츠 필터링: 유해하거나 민감한 입력과 출력을 정책 기준으로 제어하는 레이어
- 파인튜닝: 모델 가중치나 행동 특성을 특정 태스크에 맞게 조정하는 방식
- RAG: 외부 지식원을 검색해 프롬프트에 붙여 답변 근거를 만드는 방식
- 청킹: 긴 문서를 검색 가능한 작은 단위로 나누는 과정
- 경계 처리: 문장, 문단, 표, 코드 블록 같은 의미 단위를 최대한 깨지 않게 나누는 설계
